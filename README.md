# Grimório de Aventuras

Diário de campanha para RPG de mesa: rápido para anotar durante a sessão, organizado para consultar depois.

**Abrir:** https://arthurhenriquebarbosa.github.io/grimorio/

- `index.html`: o aplicativo inteiro (um arquivo só).
- `manifest.webmanifest`, `sw.js` e `icones/`: deixam o grimório instalável e abrindo sem internet.

As anotações **não** ficam aqui: cada aparelho guarda as suas no navegador e sincroniza com um repositório privado.
